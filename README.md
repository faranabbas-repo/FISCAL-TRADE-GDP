# Fiscal Balance, Trade, and GDP in SAARC Countries (2000–2024)

This project explores the relationship between fiscal policy, trade openness, and GDP in SAARC countries over the period 2000–2024. The SAARC region includes Afghanistan, Bangladesh, Bhutan, India, Maldives, Nepal, Pakistan, and Sri Lanka.

The data was retrieved using the World Bank’s World Development Indicators (WDI) via the `WDI` R package. After cleaning and filtering, the dataset was visualized and analyzed using R and Quarto.

🔗 [View the Quarto Website](https://faranabbas-repo.github.io/fiscal-trade-gdp)

📁 **Key Features**:
- Public repository with clean folder structure
- Quarto website with a summary and key visualizations
- Code and visualizations focused on economic trends in SAARC countries
